# Price Analysis Assistant — завантаження

Програма для аналізу цін до кошторисів (Windows 10/11, 64-біт).

## Завантажити

**[⬇ Завантажити останню версію (PriceAnalysisAssistant-setup.exe)](https://github.com/ruslanpanasiuk/price-analysis-assistant-download/releases/latest/download/PriceAnalysisAssistant-setup.exe)**

Усі версії — на сторінці [Releases](https://github.com/ruslanpanasiuk/price-analysis-assistant-download/releases).

## Встановлення

1. Запустіть завантажений файл. Якщо Windows покаже «Windows захистила ваш ПК» — натисніть **Докладніше → Усе одно запустити**.
2. Встановлення не потребує прав адміністратора.
3. Після запуску: **Налаштування → AI-провайдер** — вставте свій API-ключ. Як його отримати — у програмі: **Довідка → API-ключі**.

Оновлення: завантажте файл за тим самим посиланням і встановіть поверх — проєкти та налаштування збережуться.
